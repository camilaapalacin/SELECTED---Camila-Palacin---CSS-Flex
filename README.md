# SELECTED.

**Independent Electronic Music Culture**

SELECTED is an independent platform exploring underground electronic music through audiovisual sessions, conversations, events and cultural experiences.

## Live Website

Visit the published website:  
https://camilaapalacin.github.io/SELECTED---Camila-Palacin---CSS-Flex/

## Project Overview

SELECTED explores the relationship between sound, people, space and culture through a curated editorial approach to electronic music.

## Features

- Responsive navigation built with Bootstrap.
- Bootstrap carousel on the homepage.
- Bootstrap cards and reusable layout components.
- Custom CSS styling and animated marquee.
- Responsive layouts for desktop and mobile.
- Multiple pages: Home, About, Sessions, Events, Journal and Contact.

## Technologies

- HTML5
- CSS3
- Bootstrap 5.3
- Git and GitHub
- GitHub Pages

## Repository Structure

- `index.html` — Homepage
- `pages/` — Additional website pages
- `styles/style.css` — Custom styles
- `assets/` — Images and visual resources

## Deployment

The website is published using GitHub Pages from the `main` branch and the root directory.
